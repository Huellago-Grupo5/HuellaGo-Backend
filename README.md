# HuellaGo-Backend
Backend huella go 

## Documentación de la API

Con el backend iniciado localmente, abre `http://localhost:8081/swagger-ui/index.html`.
El documento OpenAPI está en `http://localhost:8081/v3/api-docs` y
`http://localhost:8081/v3/api-docs.yaml`. Usa `POST /auth/login` y copia el JWT
al botón **Authorize** para probar las rutas protegidas. Swagger está habilitado
en desarrollo; para deshabilitarlo en otro entorno configura
`HUELLAGO_SWAGGER_ENABLED=false`.
